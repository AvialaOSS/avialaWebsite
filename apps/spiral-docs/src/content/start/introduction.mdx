# Spiral 2 介绍

Spiral 2 是 Aviala Design 的 React 组件库，建在 Radix UI 和 Tailwind CSS v4 之上，设计令牌和 Figma 里的组件一一对应。

## 特性

- 设计令牌驱动：主题、密度（Default / Mobile Friendly）和 ALD 同步，改一处全站生效
- 可访问性：基于 Radix 原语，键盘和屏幕阅读器直接可用
- 组合式 API：Select、Cascader、ColorPicker 这类复杂组件能拆开来自己拼
- TypeScript 优先：类型导出完整，每个组件的 Props 都有文档

## 适用场景

- 内部产品界面开发
- 需要和 Aviala Design 设计稿对得上的体验产研项目
- 要落地主题切换、扩展品牌色的设计系统
