# 贡献 / 开发 kit

本站「开始」章节只覆盖 **消费** Spiral（安装、主题、组件用法）。

若要 **改组件库本身**（`packages/ui` / tokens / icons / 发版），请到 [developer-kit](https://github.com/AvialaOSS/developer-kit) 仓库，并以维护侧入口为准：

- [AGENTS.md](https://github.com/AvialaOSS/developer-kit/blob/main/AGENTS.md) — 维护侧 Agent 指令（monorepo、Skill、class↔CSS）
- [CONSUMER.md](https://github.com/AvialaOSS/developer-kit/blob/main/CONSUMER.md) — 业务仓消费路径（不要与 AGENTS 混用）
- 验收探针：[acceptance-probes.md](https://github.com/AvialaOSS/developer-kit/blob/main/docs/acceptance-probes.md)

本文 **不** 复制 turbo、changeset、icons:export 等 monorepo 命令。
