# 安装

## 环境要求

- Node.js 20 及以上
- React 18 及以上

## 安装

```bash
pnpm add @aviala-design/spiral
# 或 npm install / yarn add
```

`@aviala-design/tokens` 与 `@aviala-design/icons` 会作为 Spiral 的依赖自动装上，一般不必再单独安装。

## 引入样式

在应用入口只导入一份 CSS（已包含设计令牌、全部组件 effects、默认 ALD 主题，以及库构建期预编译的少量布局 utility）：

```tsx
import "@aviala-design/spiral/styles.css";
```

**不需要**安装 `tailwindcss`、配置 `@tailwindcss/vite`，也不需要 `@source` 扫描 Spiral 源码。

高级用法：若只要按需裁剪样式，仍可从 `@aviala-design/tokens` 的子路径导入单个 `*-effects.css` / `ald-theme.css`（见该包 exports）。默认路径请只用上面这一份 `styles.css`。

## 挂上 ThemeProvider

```tsx
import "@aviala-design/spiral/styles.css";
import { ThemeProvider, Button } from "@aviala-design/spiral";

export function App() {
  return (
    <ThemeProvider defaultMode="light" defaultPresetId="ald">
      <Button mode="primary">开始使用</Button>
    </ThemeProvider>
  );
}
```

`defaultPresetId="ald"` 使用内置 ALD 静态主题（变量已打进 `styles.css`）。动态品牌主题仍走 ThemeProvider 的运行时生成。

组件内置文案（分页、日期选择等）默认中文。需要英文或与业务 i18n 同步时，见 [国际化](/docs/start/locale)。

## 本地跑文档站

文档站源码在这个 `avialaWebsite` 仓库，组件库本身是通过 npm 上发布的 `@aviala-design/*` 来消费的：

```bash
npm ci
npm run dev:spiral-docs
```

默认运行在 `http://localhost:5175/docs/`。

组件库的开发在 [developer-kit](https://github.com/AvialaOSS/developer-kit) 仓库进行。改完发版后，文档站才会跟着更新。
