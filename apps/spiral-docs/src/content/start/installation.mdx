# 安装

## 环境要求

- Node.js 20 及以上
- pnpm 9 及以上

## 在 monorepo 里使用

Spiral 2 目前以 workspace 包的形式发布：

```bash
pnpm add @aviala-design/spiral @aviala-design/tokens @aviala-design/icons
```

## 引入样式

在应用入口把 Spiral 的样式和 ALD 主题一起引进来：

```tsx
import "@aviala-design/spiral/styles.css";
import "@aviala-design/tokens/ald-theme.css";
import "@aviala-design/tokens/input-effects.css";
import "@aviala-design/tokens/basic-input-effects.css";
import "@aviala-design/tokens/button-effects.css";
```

其余组件按需补上对应的效果样式，比如 `popover-effects.css`、`cascader-effects.css`、`tab-effects.css`（Tab 标签页）。

## 挂上 ThemeProvider

```tsx
import { ThemeProvider, Button } from "@aviala-design/spiral";

export function App() {
  return (
    <ThemeProvider defaultMode="light" defaultPresetId="ald">
      <Button mode="primary">开始使用</Button>
    </ThemeProvider>
  );
}
```

组件内置文案（分页、日期选择等）默认中文。需要英文或与业务 i18n 同步时，见 [国际化](/docs/spiral/start/locale)。

## 本地跑文档站

文档站源码在这个 `avialaWebsite` 仓库，组件库本身是通过 npm 上发布的 `@aviala-design/*` 来消费的：

```bash
npm ci
npm run dev:spiral-docs
```

默认运行在 `http://localhost:5175/docs/spiral/`。

组件库的开发在 [spiral-2](https://github.com/AvialaOSS/spiral-2) 仓库进行。改完发版后，文档站才会跟着更新。
