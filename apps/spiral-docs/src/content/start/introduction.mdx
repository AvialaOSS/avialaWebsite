# Spiral 介绍

Spiral 是 Aviala Design 的 React 组件库，建在 Radix UI 之上，通过 Theme Engine 的基础、语义和组件 Token 对齐 Figma 设计。业务应用只需安装发布包、导入一份 CSS，并用 `ThemeProvider` 包裹——**不需要**为 Spiral 单独配置 Tailwind。3.1 的新增能力、兼容关系与尚未完成的设计验收见 [升级指南](/docs/start/migration-3-1)。

## 消费侧快速路径

```tsx
import "@aviala-design/spiral/styles.css";
import { ThemeProvider, Button } from "@aviala-design/spiral";
```

详见 [安装](/docs/start/installation)。英文 / Agent 入口：[CONSUMER.md](https://github.com/AvialaOSS/developer-kit/blob/main/CONSUMER.md)。

## 特性

- 设计令牌驱动：标准项目控制亮暗主题、密度（Default / Mobile Friendly）与效果开关；Web 与 Figma 通过各自适配器消费同一份定义
- 可访问性：基于 Radix 原语，键盘和屏幕阅读器直接可用
- 组合式 API：Select、Cascader、ColorPicker 这类复杂组件能拆开来自己拼
- TypeScript 优先：类型导出完整，每个组件的 Props 都有文档

## 适用场景

- 内部产品界面开发
- 需要和 Aviala Design 设计稿对得上的体验产研项目
- 要落地主题切换、扩展品牌色的设计系统
